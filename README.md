# みんなでポチッ（アンケート・早押し v0.14.4）

会場の人がスマホでQRを読んで参加、マスターがPC（またはスマホのリモコン）で出題、モニタに結果をどーん、のアンケートアプリ。

ファイル：
- `index_0.14.4.html` … アプリ本体（アップするときは `index.html` に名前を変える）
- `sounds/` … 効果音（9個のMP3。v0.12.1 で buzz.mp3 が増えた）。`index.html` と同じ場所に `sounds` フォルダごと置く
- `supabase_update_0.13.sql` … **v0.12 の追加SQLを Run ずみの人用**（v0.13.1〜v0.14.4 はSQLの追加なし。0.13 を Run ずみなら何もしなくてOK）
- `supabase_setup_0.13.sql` … はじめて Supabase を準備する人用（全部入り。合言葉の行を書きかえてから Run）
- ファイル名の `_0.14.4` はバージョン番号。更新するたびに数字が上がる

---

## 1. まずは「おためしモード」で触ってみる

`index.html` を GitHub Pages に置いて開くだけ。サーバー設定がないと自動でおためしモードになる。

- このブラウザの中だけで動く（同じブラウザのタブ同士でテスト）
- 部屋をつくる → 「URL・QR」→「新しいタブで参加者として開く」で参加者を増やせる
- 「ダミーを10人入れる」で、出題すると勝手に投票してくれる
- 「表示用ウィンドウを開く」でモニタ画面

※ スマホなど別の機械からは参加できない。それは本番モードで。

## 2. 本番モード（Supabase）にする

1. Supabase でプロジェクトをつくる（無料プランでOK）
2. **SQL Editor** を開いて、`supabase_setup_0.13.sql` を全部貼る（もう準備ずみなら、まだ流していない update ファイルだけを古い順に Run）
3. いちばん下の `'ここをパスワードに'` を自分のマスターパスワードに書きかえて **Run**
4. **Project Settings → API** から「Project URL」と「anon public key」をコピー
5. `index.html` の上のほうの `CONFIG` に貼る

```js
const CONFIG = {
  SUPABASE_URL: 'https://xxxxxxxx.supabase.co',
  SUPABASE_ANON_KEY: 'eyJhbGciOi...',
};
```

6. GitHub Pages に上げなおして完了
   - 本番モードでも、URLの最後に `?demo=1` をつけるとおためしモードで開ける

**確認しておくこと**
- Realtime の設定で「Private channels only（プライベートチャンネルのみ）」がオフになっていること
- 無料プランの同時接続数の上限（100人＋モニタ＋マスターが入るか）を、本番前に Supabase のプラン表で確認
- 本番前に、実際のスマホ数台で一度リハーサル推奨

## 3. 当日の使い方

1. PCでトップを開き、部屋の名前を入れて「部屋をつくる」（名前のあつかいは質問ごとに選ぶ。さいしょは 👤 匿名）
2. モニタはPCに **「拡張」** でつなぐ（Windows：`Win+P`→拡張、Mac：ミラーリングをオフ）
3. 「表示用ウィンドウを開く」→ そのウィンドウをモニタ側へ移動 → ダブルクリック（または F キー）で全画面
4. モニタに出たQRとカギの数字で、観客が参加
5. 「サッとアンケート」か「この部屋の質問」から出題 → 時間が来たら自動で締め切り（「締め切る」ボタンで途中でも）
6. 「あとで発表」の質問は「🎉 結果発表！」を押すとモニタに結果

**質問を前もって用意する**
- 用意した質問は **部屋ごと** にサーバーへ保存される（新しい部屋はまっさら。スマホのリモコンからも見える）
- 前日：練習用の部屋で質問をつくって「✏️ 質問をつくる」→「📤 ファイルに書き出す」（質問セット：部屋の名前・名前のあつかい・質問が入る）
- 当日：トップの「▼ そのほか」→「📂 質問セットのファイルから部屋をつくる」で質問セット（または記録ファイル）を選んでから「部屋をつくる」→ 名前・質問が入った部屋ができる
- 部屋は当日につくるのが安全（24時間で消えるため）

**トップページ（v0.14）**
- 「部屋の名前」と「部屋をつくる」だけに。名前のあつかいの選択はなくなった（質問ごとに選ぶ。さいしょは 👤 匿名）
- 「▼ そのほか」の中に：質問セットのファイルから部屋をつくる／記録を見る・このPCの控え／部屋コードで参加
- 質問セットのファイルから部屋をつくるときは、ファイルに入っている部屋の設定（名前のあつかい）を引きつぐ

**操作画面（v0.14.4）**
- 「⚡ サッと出題」は「⚡ サッとアンケート」に名前を変えた
- 待機中の「🔴 早押しをはじめる」ボタンは消した（左の「🔴 早押し」の箱から始めてね）
- 🖥 モニタのようす：右上の［小］［大］で大きさを切りかえ（このPCに覚える。さいしょは小）
  - 小のときは右に「いまの様子」：👥 参加人数／📮 回答・とどいた件数（早押しは押した人数）／⏱ のこり時間／🔊 音の鳴る場所
- ✍️ 自由に書くをタイルで出しているとき、**モニタのようすのタイルをクリック** → その1件をモニタに大きく（「✓ 紹介ずみ」もつく）
  - 大きく出ているときに、モニタのようすをもう一回クリック、または「🧱 タイルにもどる」→ タイルにもどる（スクロールの位置もそのまま）
  - 表示用ウィンドウ（本番のモニタ）はクリックしても何も起きない

**🔑 カギの数字をモニタでかくす（v0.14）**
- 操作画面の上「カギ ○○○○」の横のボタン：「🖥 モニタに表示中」⇔「🙈 モニタではかくし中」
- かくすと、モニタは QR コードだけ ＋「🔑 会場でお伝えします」。自由に書くの受付中のQRのところも同じ
- QR コードにはカギの数字は入っていないので、オンライン配信でQRが見えても、数字を知らない人は入れない
- 部屋ごとの設定（表示用ウィンドウ・PC・スマホで共通）。さいしょは「表示中」
- 配信に数字が映ってしまったら「↻ 作り直す」（もう入っている人はそのまま）

**🔒👤📢 名前のあつかいは質問ごと（v0.11）**
- 質問をつくるとき（サッとアンケートでも）「名前のあつかい」を選ぶ。部屋の設定は、新しい質問の最初の値
- 参加者のスマホには、質問の上に「📢 記名の質問：名前がモニタに出ます」などのバッジが毎回出る
- 出題したら、その質問のあつかいは変えられない（サーバー側で固定。完全匿名の質問は名前とつながらない形で保存）
- 履歴・記録ファイル・CSV にも質問ごとのあつかいが残る

**❓ 質問文をかくす（v0.11）**
- ふだんは質問文が出る。質問をつくるときに「モニタに質問文を出さない」に印（サッとアンケートでは、出題すると印は自動ではずれる） → モニタは「❓ 何の質問でしょう？」（画像もかくれる）。スマホには質問が出る
- 操作画面の「🎉 質問を発表！」でモニタに質問文が出る（roll_end の音）。「❓ モニタの質問文をかくす」で途中からかくすこともできる

**🔴 早押し（v0.12）**
- 進行タブの「🔴 早押しをはじめる」→ 参加者のスマホに大きな丸いボタン（早押しはいつも記名）
- フライング規制なし。問題を読んでいる途中でも押せる。1つの問題で数えるのは1人1回目だけ
- 順番はサーバーに届いた順（スマホの時計は関係なし）
- モニタ：上位5人（2位からは「+0.38秒」）。操作画面：全員の順番
- だれかが新しく押すたびに buzz（早押しボタンの音）が鳴る。鳴っているあいだ（約0.8秒）に押された分は鳴らさない（音が重ならない）
- スマホ：押すとボタンがグッとへこむ →「🥇 1位！」「8位」＋「1位と +0.23秒」。Android はブルッ（iPhone は iOS 18 以降で軽くコツッとなることがある）
- **🎵 デデン！（次の問題）と第◯問（v0.14.4）**
  - デデン！を押すと、押した人が消えてデデンの音
  - 第◯問が1つ進むのは、**⭕ ピンポンか ❌ ブーを鳴らしたあと**のデデン！だけ（早押しをはじめて最初のデデン！は第1問）
  - ピンポンもブーも鳴らしていないのにデデン！→ だれか押していたら「押した人を消して、第◯問をやりなおしますか？」と確認（番号はそのまま）。だれも押していなければ音だけ
  - つまり：まちがえて早く押されたら「↺ リセット」か「デデン！」で仕切りなおし。デデン！連打しても番号はふえない
  - だれも押さなかった（スルー）ときは、❌ ブーを鳴らしてからデデン！、または「第◯問を直す」の ＋
  - 操作画面に「→ 次のデデン！で第◯問」と出ていれば、次のデデン！で番号が進む
  - デデン！の直後、スマホに新しい問題がとどく前に押した人は、自動で新しい問題で押しなおす
  - モニタ（v0.14.4）：番号があるときは上に大きく黄色で「第3問」（「🔴 早押し」の文字は出さない）。番号を出さない設定のときや、デデン！前のスイッチチェック中は「🔴 早押し」
  - ⚙️ 設定の「第◯問をモニタ・参加者のスマホに出す」（部屋の設定・さいしょはオン）。オフでも操作画面には出る
- 「第◯問を直す」の −／＋：番号を手で直す（押した人は消えない）
- 「↺ リセット（押した人を消すだけ）」：番号はそのまま。やりなおしやスイッチチェック用
- 早押しをはじめたときは番号なし（モニタ・スマホにも第◯問は出ない）＝スイッチチェック。前の続きの番号はおぼえていて、デデン！でその次から
- 「⭕ ピンポン」「❌ ブー」。鳴る場所は下の「効果音を鳴らす場所」のルール。音量はその下のつまみ（部屋の音量）
- 「早押しを終わる」で待機画面へ
- スイッチチェック：早押しをはじめて「ためしに押して〜」→ デデン！で第1問へ（記録には「スイッチチェック」として残る）
- 記録：だれが・第何問で・何位・何秒で押したかを保存（📜 履歴・記録ファイル・CSV にも出る）。点数やランキングは、あとでこの記録から付けられるようにしてある
- テスト用ダミーも、早押しのたびに勝手に押してくれる

**🔊 効果音を鳴らす場所（v0.13）**
- 表示用ウィンドウが開いていれば、そこから鳴る（今までどおり）
- 開いていなければ、**さいごにさわった操作画面**（PC・リモコンのスマホ）から鳴る。表示用ウィンドウを閉じたり開いたりしても、数秒で自動で切りかわる
- アンケートの音・早押しボタン・デデン／ピンポン／ブー、ぜんぶ同じルール
- いまどこで鳴るかは、操作画面のいちばん上に出る（🔊 音：表示用ウィンドウ／この画面／🔇 ほかの操作画面／⚠️ どこからも鳴りません）
- ⚙️ 設定の「この PC・スマホで効果音を鳴らす：自動／この画面では鳴らさない」はその機械だけの設定。「鳴らさない」にしても、ほかからは鳴る
- 効果音のオン・オフ・音量・音ごとの大きさ（▼ 🎚 細かい調整）は **部屋ごと** の設定になった（表示用ウィンドウ・PC・スマホで共通。前のバージョンの「そのPCに覚える」音量は使わなくなった）。デデンは最初から 70%
- パワポを映しながら早押し：PCはパワポ、スマホで「リモコン用」を開いて操作 → 音はスマホから鳴る（iPhone はマナーモードを切る）

**✍️ 自由に書く**
- 「ボタン」で「✍️ 自由に書く（感想・大喜利など）」を選ぶ。制限時間は自動で「制限なし」になる（変えてもOK）
- 参加者のスマホに入力らん。140文字まで・1人1件・締め切りまでは直せる／取り消せる
- 受付中のモニタ：質問＋「✍️ スマホで書いてね！」＋「📮 とどいた○件」。中身はマスターだけに見える
- 操作画面の「📮 とどいた文章」にきた順でタイル表示 →「🖥 モニタに出す」でモニタにどーん（音なし）
  - 「▶ 次の文章」で、まだ出していないものを順番に。「表示を消す」で件数の画面にもどる。紹介ずみは「✓ 紹介ずみ」
  - 出た人のスマホには「🎉 あなたのコメントがモニタに出ました！」
- 名前：「自由に書く」を選ぶと名前のあつかいは自動で 📢 記名 に（変えられる。選択肢の質問にもどすと最初の設定にもどる）
  - 📢 記名 → モニタにも「― たろう さん」／👤 匿名 → マスターだけ見える／🔒 完全匿名 → だれにもわからない
  - 🙈 スマホで「匿名で送る」に印 → その文章は名前とつながらない形で保存（モニタにもマスターにも名前は出ない。操作画面では「🙈 匿名」）。質問ごとに「選べるようにする」をオフにもできる
- 休憩中に集めて最後に読む：出題 → 休憩後に「⏹ 締め切る」→ ほかを進める →「📜 履歴」でその質問の「▼ 文章を見る」をひらいて「🖥 モニタに出す」（履歴の文章は、いつもたたんだ状態から。ひらいたものは「最新にする」してもひらいたまま）
- お題の画像を付けると、大喜利の答えといっしょにモニタに出る
- 受付中のモニタに、参加用QRとカギの数字も出る（途中参加OK）
- 「🧱 ぜんぶタイルで出す」：来た順にポポポンとタイルでならぶ（記名の質問なら名前も）。多いときは「▲ 上へ／▼ 下へ」、表示用ウィンドウの上ならマウスホイール・↑↓キー・スペースでも動く。履歴からも出せる
- 答えだけ見て質問を当てるゲーム：「質問文をかくす」＋「自由に書く」で出題 → タイルで出す → 当ててもらう →「🎉 質問を発表！」
- 記録ファイル・CSVにも文章が入る（CSVは1行1件）

**効果音**（鳴る場所は上の「効果音を鳴らす場所」）
- 出題 → shutsudai ／ 制限時間のあいだ → timer（残り10秒から timer_fast）／ 時間ゼロ・締め切り → gong
- 「🎉 結果発表！」→ roll（約4.6秒、もにたとスマホは「🥁 結果発表…！」）→ roll_end と同時に結果。「ロールなしで発表」に印でロールをとばす
- 「投票中も見せる」の質問は gong だけ。「制限なし」の質問はタイマー音なし
- 表示用ウィンドウは一度クリックしないと音が出ない（ブラウザの決まり）。左下の「🔇 クリックして音をオンにする」が消えればOK
- ⚙️ 設定で効果音オン／オフ・音量・音ごとの大きさ・試し鳴らし（部屋ごと）。sounds フォルダが無いときは手作りの音で代わりに鳴る
- buzz は早押しボタン、shutsudai / seikai / fuseikai は早押しの「🎵 デデン！」「⭕ ピンポン」「❌ ブー」でも使う
- 効果音素材：効果音ラボ（https://soundeffect-lab.info/）。素材そのものを配布するページやリンクは作らないこと
- 早押しボタンの音（buzz.mp3）：OtoLogic（https://otologic.jp/、CC BY 4.0）。クレジット表記が必要なので、📖 使い方のいちばん下に「OtoLogic」を出している（消さないこと）

**部屋の名前を変える**：操作画面の上の「部屋 ○○ ✏️」から。モニタ・参加者のスマホにもすぐ反映。

**📖 使い方**：トップと操作画面の右上。参加者のスマホには「❓ 参加のしかた」。

**画像**（「✏️ 質問をつくる」タブの「🖼 画像」）
- 質問に1枚、選択肢ごとに1枚ずつ付けられる（どれも任意。画像なしの選択肢とまぜてもOK）
- 選んだ瞬間に自動で縮小＋JPEG圧縮（質問は長い辺1280px、選択肢は640px。「きれい」なら1600px／900px）。形は変えない（切らない）
- 選択肢の画像の見せ方：🖼 全体を見せる（余白が出ることも）／✂️ 枠いっぱい（はしが切れることも）
- 「スマホにも画像を出す」：オンだとスマホのボタンが画像カードに。🔍で大きく見られる
- 画像は部屋の中（サーバー）にしまわれ、部屋と一緒に24時間で消える。質問セット・記録ファイルには画像も一緒に入る（このPCの控えには入らない）
- 通信の目安：6択ぜんぶ画像で100人だと1問で数十MB。無料プランの月5GBなら、ふつうのイベントは大丈夫
- 「サッとアンケート」では画像は使えない（質問をつくるタブで用意してね）

**スマホにも結果**：質問ごとの「結果発表のとき、参加者のスマホにもグラフを出す」（最初はオン）。進行中も「📱 スマホに結果」ボタンで切りかえられる。スマホに出るのは人数と割合だけで、名前は出ない。リモート参加の人にも便利。

**マスターパスワードを覚える**：部屋をつくるとき「このPCで覚える」に印を付けると、次からは入力なしでつくれる（共用PCでは外す）。合わなくなったら自動で忘れて、入力欄にもどる。

**⚙️ 設定**（操作画面の右上・このPCに覚える）
- 🧪 テスト用ダミーを使う：進行タブにダミーの箱が出る（10人／30人入れる、出題したら自動投票、全員帰らせる）。本番の前に「全員帰らせる」→ 設定でオフ
- 💾 このPCのブラウザに結果の控えを自動で残す（最初はオン）
- 🔑 保存したマスターパスワードを忘れる

**スマホをリモコンにする**：「URL・QR」→「リモコン用」のQRをスマホで読む。モニタ側のPCでは「表示用URL」を開く。
（表示用・リモコン用URLにはマスターのカギが入っているので、観客に見せないこと）

**履歴（📜 タブ）**：その部屋で出した質問と結果が新しい順に並ぶ。「🖥 結果をモニタに出す」でさっきの結果をもう一度モニタへ、「🔁 もう一度出題」で同じ質問をもう一回。

**記録を残す**
- 「💾 結果を保存」→ **記録ファイル（JSON）** を保存しておくと、サーバーから消えたあとでもトップの「📂 記録を見る」から質問・設定・結果が全部見られる（「この質問で新しい部屋をつくる」もできる）
- 24時間以内なら、同じブラウザのトップ「このブラウザでつくった部屋」か、リモコン用URLから入りなおして保存できる
- 「部屋を終了」を押すと、サーバーのデータはその場で消える
- ⚙️ 設定の「このPCのブラウザに結果の控えを自動で残す」（最初はオン）：オンだと、保存し忘れてもトップの「このPCに残っている控え」から見られる。共用PCではオフ推奨

**変な人がまぎれたら**：上の「↻ 作り直す」でカギの数字を変える（新しく入る人だけに効く）。
