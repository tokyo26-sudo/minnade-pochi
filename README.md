# みんなでポチッ（アンケート機能 v0.8）

会場の人がスマホでQRを読んで参加、マスターがPC（またはスマホのリモコン）で出題、モニタに結果をどーん、のアンケートアプリ。

ファイル：
- `index_0.8.html` … アプリ本体（これ1つでぜんぶ。アップするときは `index.html` に名前を変える）
- `supabase_update_0.8.sql` … **v0.7 の追加SQLを Run ずみの人用**（これだけ Run すればOK）
- `supabase_setup_0.8.sql` … はじめて Supabase を準備する人用（全部入り。合言葉の行を書きかえてから Run）
- ファイル名の `_0.8` はバージョン番号。更新するたびに数字が上がる

---

## 1. まずは「おためしモード」で触ってみる

`index.html` を GitHub Pages に置いて開くだけ。サーバー設定がないと自動でおためしモードになる。

- このブラウザの中だけで動く（同じブラウザのタブ同士でテスト）
- 部屋をつくる → 「URL・QR」→「新しいタブで参加者として開く」で参加者を増やせる
- 「ダミーを10人入れる」で、出題すると勝手に投票してくれる
- 「表示用ウィンドウを開く」でモニタ画面

※ スマホなど別の機械からは参加できない。それは本番モードで。

## 2. 本番モード（Supabase）にする

1. Supabase でプロジェクトをつくる（無料プランでOK）
2. **SQL Editor** を開いて、`supabase_setup_0.6.sql` を全部貼る（もう準備ずみなら、まだ流していない update ファイルだけを古い順に Run）
3. いちばん下の `'ここをパスワードに'` を自分のマスターパスワードに書きかえて **Run**
4. **Project Settings → API** から「Project URL」と「anon public key」をコピー
5. `index.html` の上のほうの `CONFIG` に貼る

```js
const CONFIG = {
  SUPABASE_URL: 'https://xxxxxxxx.supabase.co',
  SUPABASE_ANON_KEY: 'eyJhbGciOi...',
};
```

6. GitHub Pages に上げなおして完了
   - 本番モードでも、URLの最後に `?demo=1` をつけるとおためしモードで開ける

**確認しておくこと**
- Realtime の設定で「Private channels only（プライベートチャンネルのみ）」がオフになっていること
- 無料プランの同時接続数の上限（100人＋モニタ＋マスターが入るか）を、本番前に Supabase のプラン表で確認
- 本番前に、実際のスマホ数台で一度リハーサル推奨

## 3. 当日の使い方

1. PCでトップを開き「部屋をつくる」（名前のあつかい：完全匿名／匿名／記名を選ぶ。あとで変えられない）
2. モニタはPCに **「拡張」** でつなぐ（Windows：`Win+P`→拡張、Mac：ミラーリングをオフ）
3. 「表示用ウィンドウを開く」→ そのウィンドウをモニタ側へ移動 → ダブルクリック（または F キー）で全画面
4. モニタに出たQRとカギの数字で、観客が参加
5. 「サッと出題」か「この部屋の質問」から出題 → 時間が来たら自動で締め切り（「締め切る」ボタンで途中でも）
6. 「あとで発表」の質問は「🎉 結果発表！」を押すとモニタに結果

**質問を前もって用意する**
- 用意した質問は **部屋ごと** にサーバーへ保存される（新しい部屋はまっさら。スマホのリモコンからも見える）
- 前日：練習用の部屋で質問をつくって「✏️ 質問をつくる」→「📤 ファイルに書き出す」（質問セット：部屋の名前・名前のあつかい・質問が入る）
- 当日：トップの「📂 ファイルから読みこむ」で質問セット（または記録ファイル）を選んでから「部屋をつくる」→ 名前・あつかい・質問が入った部屋ができる（あつかいは作る前なら変えられる）
- 部屋は当日につくるのが安全（24時間で消えるため）

**画像**（「✏️ 質問をつくる」タブの「🖼 画像」）
- 質問に1枚、選択肢ごとに1枚ずつ付けられる（どれも任意。画像なしの選択肢とまぜてもOK）
- 選んだ瞬間に自動で縮小＋JPEG圧縮（質問は長い辺1280px、選択肢は640px。「きれい」なら1600px／900px）。形は変えない（切らない）
- 選択肢の画像の見せ方：🖼 全体を見せる（余白が出ることも）／✂️ 枠いっぱい（はしが切れることも）
- 「スマホにも画像を出す」：オンだとスマホのボタンが画像カードに。🔍で大きく見られる
- 画像は部屋の中（サーバー）にしまわれ、部屋と一緒に24時間で消える。質問セット・記録ファイルには画像も一緒に入る（このPCの控えには入らない）
- 通信の目安：6択ぜんぶ画像で100人だと1問で数十MB。無料プランの月5GBなら、ふつうのイベントは大丈夫
- 「サッと出題」では画像は使えない（質問をつくるタブで用意してね）

**スマホにも結果**：質問ごとの「結果発表のとき、参加者のスマホにもグラフを出す」（最初はオン）。進行中も「📱 スマホに結果」ボタンで切りかえられる。スマホに出るのは人数と割合だけで、名前は出ない。リモート参加の人にも便利。

**マスターパスワードを覚える**：部屋をつくるとき「このPCで覚える」に印を付けると、次からは入力なしでつくれる（共用PCでは外す）。合わなくなったら自動で忘れて、入力欄にもどる。

**⚙️ 設定**（操作画面の右上・このPCに覚える）
- 🧪 テスト用ダミーを使う：進行タブにダミーの箱が出る（10人／30人入れる、出題したら自動投票、全員帰らせる）。本番の前に「全員帰らせる」→ 設定でオフ
- 💾 このPCのブラウザに結果の控えを自動で残す（最初はオン）
- 🔑 保存したマスターパスワードを忘れる

**スマホをリモコンにする**：「URL・QR」→「リモコン用」のQRをスマホで読む。モニタ側のPCでは「表示用URL」を開く。
（表示用・リモコン用URLにはマスターのカギが入っているので、観客に見せないこと）

**履歴（📜 タブ）**：その部屋で出した質問と結果が新しい順に並ぶ。「🖥 結果をモニタに出す」でさっきの結果をもう一度モニタへ、「🔁 もう一度出題」で同じ質問をもう一回。

**記録を残す**
- 「💾 結果を保存」→ **記録ファイル（JSON）** を保存しておくと、サーバーから消えたあとでもトップの「📂 記録を見る」から質問・設定・結果が全部見られる（「この質問で新しい部屋をつくる」もできる）
- 24時間以内なら、同じブラウザのトップ「このブラウザでつくった部屋」か、リモコン用URLから入りなおして保存できる
- 「部屋を終了」を押すと、サーバーのデータはその場で消える
- ⚙️ 設定の「このPCのブラウザに結果の控えを自動で残す」（最初はオン）：オンだと、保存し忘れてもトップの「このPCに残っている控え」から見られる。共用PCではオフ推奨

**変な人がまぎれたら**：上の「↻ 作り直す」でカギの数字を変える（新しく入る人だけに効く）。

## 4. しくみメモ

- 締め切り時刻はサーバーの時計で決めて、サーバー側でも受付チェック（スマホの時計がずれていても公平）
- 1台のスマホ＝1票。締め切りまでは何度でも変更OK（最後の1つだけ数える）
- 完全匿名モードでは、投票は名前とつながらない「でたらめな記号」で保存される
- 部屋・参加者・結果は24時間で自動的に消える。残したいときは「結果を保存」（記録ファイルJSON / CSV）
- 用意した質問は部屋の中（サーバー）に保存。部屋と一緒に消えるので、別の日に使うときは書き出しておく
